\projectheading{MLLM reasoning and post-training\projecttopic{Thinking with latent visual memory}}{2026.4 - 2026.10}
\paperentry{ReMAP: Restoring the Perceptual Cycle with Reasoning-Time Latent Visual Memory {\normalfont\href{https://arxiv.org/abs/2610.05097}{[arXiv]}}}{{\normalfont\color{black}\textbf{指导教师：}北京大学 \quad 计算机学院 \quad 仉尚航助理教授}}{Submitted to ICLR 2027}{第一作者}
\begin{itemize}[leftmargin=*, nosep, itemsep=2pt]
    \item \textbf{发现：}推理链越长，MLLM 对初始图像的注意力越弱，grounding 随之减弱。对照分析推理时视觉记忆的构建、组织与访问，发现局部证据需全局上下文才能读懂、紧凑 latent 表示可兼顾精度与开销、访问收益取决于推理状态。
    \item \textbf{方法与结果：}据此提出 ReMAP：问题条件化的 Global 记忆与推理状态驱动的 Local 记忆均以紧凑 latent token 插入推理序列，并以分支 rollout 强化学习训练访问策略，决定何时调用何种记忆。在全部 4 个多图基准上超越已有视觉记忆方法（MuirBench / MIMIC 超出此前最优 8.38 / 14.84 个百分点），并减少 51.0–76.8\% 的视觉 token。
\end{itemize}
